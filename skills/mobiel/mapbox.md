# Mapbox

| | |
| --- | --- |
| **Maker** | Mapbox · officiële Claude-marketplace |
| **Werkt in** | Claude Code |
| **Kosten** | Plugin gratis; je hebt een Mapbox-account nodig |
| **Bron** | [www.mapbox.com](https://www.mapbox.com) |

## Wat doet het?

Skills en MCP-servers van Mapbox voor locatiebewuste apps: geografische tools, stijlbeheer en patronen voor web, iOS, Android en AI-agentframeworks.

## Wanneer gebruik je het?

* Je app toont kaarten of werkt met locaties.

## Voorbeelden

{% code title="Voorbeeld 1: wat je typt" overflow="wrap" %}
```
Toon alle meldingen van vandaag als markers op een Mapbox-kaart in mijn iOS-app.
```
{% endcode %}

**Wat je krijgt:** SwiftUI-code met een Mapbox-kaart en markers.

## Installeren

{% tabs %}
{% tab title="Claude Code" %}
Deze plugin staat in de **officiële Anthropic-marketplace**, die standaard al gekoppeld is:

```bash
/plugin install mapbox@claude-plugins-official
```

Of blader via `/plugin` → **Discover** en kies de plugin uit de lijst.
{% endtab %}
{% endtabs %}
