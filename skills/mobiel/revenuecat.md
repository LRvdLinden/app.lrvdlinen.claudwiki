# RevenueCat

| | |
| --- | --- |
| **Maker** | RevenueCat · officiële Claude-marketplace |
| **Werkt in** | Claude Code |
| **Kosten** | Plugin gratis; je hebt een RevenueCat-account nodig |
| **Bron** | [www.revenuecat.com](https://www.revenuecat.com) |

## Wat doet het?

Met de RevenueCat-plugin configureert Claude je in-app-aankopen: projecten, apps, producten, entitlements en offerings, zonder dat je het RevenueCat-dashboard hoeft te openen. Ideaal voor iOS- en Android-apps met abonnementen.

## Wanneer gebruik je het?

* Je wilt een abonnement of eenmalige aankoop in je app.

## Voorbeelden

{% code title="Voorbeeld 1: wat je typt" overflow="wrap" %}
```
Maak een offering 'Pro' met een maand- en jaarabonnement.
```
{% endcode %}

**Wat je krijgt:** Een kant-en-klare offering in RevenueCat.

## Installeren

{% tabs %}
{% tab title="Claude Code" %}
Deze plugin staat in de **officiële Anthropic-marketplace**, die standaard al gekoppeld is:

```bash
/plugin install revenuecat@claude-plugins-official
```

Of blader via `/plugin` → **Discover** en kies de plugin uit de lijst.
{% endtab %}
{% endtabs %}

{% hint style="warning" %}
Community-skills zijn niet door Anthropic gecontroleerd. Lees de `SKILL.md` voordat je installeert. Zie [Veilig installeren](../../basis/veiligheid.md).
{% endhint %}
