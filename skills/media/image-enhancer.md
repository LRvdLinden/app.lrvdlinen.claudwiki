# Image Enhancer

| | |
| --- | --- |
| **Maker** | ComposioHQ (community) |
| **Werkt in** | Claude Code |
| **Kosten** | Gratis |
| **Bron** | [github.com/ComposioHQ/awesome-claude-skills/tree/master/image-enhancer](https://github.com/ComposioHQ/awesome-claude-skills/tree/master/image-enhancer) |

## Wat doet het?

Verbetert resolutie, scherpte en helderheid van afbeeldingen, vooral screenshots. Ideaal voor documentatie, presentaties en social media.

## Wanneer gebruik je het?

* Je screenshots zien er wazig uit in je presentatie of App Store-pagina.

## Voorbeelden

{% code title="Voorbeeld 1: wat je typt" overflow="wrap" %}
```
Maak alle screenshots in deze map scherper voor mijn presentatie.
```
{% endcode %}

**Wat je krijgt:** Verbeterde afbeeldingen.

## Installeren

{% tabs %}
{% tab title="Handmatig" %}
Kopieer de skillmap naar je persoonlijke skills-map (voor alle projecten) of naar `.claude/skills/` in één project:

```bash
git clone https://github.com/ComposioHQ/awesome-claude-skills.git
cp -r awesome-claude-skills/image-enhancer ~/.claude/skills/
```
{% endtab %}
{% endtabs %}
