# CSV Data Summarizer

| | |
| --- | --- |
| **Maker** | coffeefuelbump (community) |
| **Werkt in** | Claude-app, Claude Code |
| **Kosten** | Gratis |
| **Bron** | [github.com/coffeefuelbump/csv-data-summarizer-claude-skill](https://github.com/coffeefuelbump/csv-data-summarizer-claude-skill) |

## Wat doet het?

Herkent automatisch wat voor data je hebt (verkoop, klanten, financieel, enquête) en maakt een complete analyse met statistieken, verbanden, verdelingen, trends en visualisaties, zonder dat je eerst hoeft te zeggen wat je wilt weten.

## Wanneer gebruik je het?

* Je hebt een export en wilt snel weten wat erin zit.

## Voorbeelden

{% code title="Voorbeeld 1: wat je typt" overflow="wrap" %}
```
(upload enquete.csv)
```
{% endcode %}

**Wat je krijgt:** Een samenvatting met de belangrijkste inzichten en grafieken.

## Installeren

{% tabs %}
{% tab title="Claude-app" %}
1. Download de repo als ZIP: [github.com/coffeefuelbump/csv-data-summarizer-claude-skill](https://github.com/coffeefuelbump/csv-data-summarizer-claude-skill) → **Code → Download ZIP**.
2. Pak uit en zoek de map `(de hoofdmap met SKILL.md)` (daarin staat `SKILL.md`).
3. Maak van **alleen die map** een nieuwe ZIP. De mapnaam moet gelijk zijn aan de skillnaam.
4. Ga naar **Instellingen → Mogelijkheden → Skills** en klik op **Skill uploaden**.
5. Zet de skill aan.

Skills in de Claude-app vragen een Pro-, Max-, Team- of Enterprise-abonnement en **Code-uitvoering en bestanden maken** moet aanstaan.
{% endtab %}
{% endtabs %}
