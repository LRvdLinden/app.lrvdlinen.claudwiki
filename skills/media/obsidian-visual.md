# Obsidian Visual Skills

| | |
| --- | --- |
| **Maker** | Axton Liu (community) |
| **Werkt in** | Claude Code |
| **Kosten** | Gratis |
| **Bron** | [github.com/axtonliu/axton-obsidian-visual-skills](https://github.com/axtonliu/axton-obsidian-visual-skills) |

## Wat doet het?

Drie skills: **excalidraw-diagram**, **mermaid-visualizer** en **obsidian-canvas-creator**. Ze zetten tekst om in diagrammen die je direct in Obsidian opent.

## Wanneer gebruik je het?

* Je gebruikt Obsidian en wilt notities visualiseren.

## Voorbeelden

{% code title="Voorbeeld 1: wat je typt" overflow="wrap" %}
```
Maak een Obsidian-canvas van deze projectnotities.
```
{% endcode %}

**Wat je krijgt:** Een .canvas-bestand met kaarten en verbindingen.

## Installeren

{% tabs %}
{% tab title="Claude Code" %}
Voeg eerst de marketplace toe en installeer daarna de plugin. Typ dit in een Claude Code-sessie:

```bash
/plugin marketplace add axtonliu/axton-obsidian-visual-skills
/plugin install obsidian-visual-skills
```

Herstart Claude Code als de skill niet meteen verschijnt. Controleer met `/plugin` of hij aanstaat.
{% endtab %}
{% endtabs %}

{% hint style="warning" %}
Community-skills zijn niet door Anthropic gecontroleerd. Lees de `SKILL.md` voordat je installeert. Zie [Veilig installeren](../../basis/veiligheid.md).
{% endhint %}
