## Wat doet het?

Een SEO-plugin met tientallen subskills en gespecialiseerde agents: technische SEO, Core Web Vitals, E-E-A-T, schema.org, AI-zoekmachines (GEO), lokale SEO, e-commerce en internationale SEO.

## Wanneer gebruik je het?

* Je wilt je website laten doorlichten voordat je hem promoot.

## Installeren

{% tabs %}
{% tab title="Claude Code" %}
Voeg eerst de marketplace toe en installeer daarna de plugin. Typ dit in een Claude Code-sessie:

```bash
/plugin marketplace add AgriciDaniel/claude-seo
/plugin install claude-seo@agricidaniel-claude-seo
```

Herstart Claude Code als de skill niet meteen verschijnt. Controleer met `/plugin` of hij aanstaat.
{% endtab %}
{% endtabs %}

Community-skills zijn niet door Anthropic gecontroleerd. Lees de `SKILL.md` voordat je installeert. Zie [Veilig installeren](../../basis/veiligheid.md).
