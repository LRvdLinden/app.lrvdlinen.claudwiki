| | |
| --- | --- |
| **Maker** | Exa · officiële Claude-marketplace |
| **Werkt in** | Claude Code |
| **Kosten** | Plugin gratis; je hebt een API-sleutel van Exa nodig |

## Wat doet het?

Exa geeft Claude krachtige webzoektools en onderzoeksskills: grondig zoeken op het web, mensen en bedrijven onderzoeken, wetenschappelijke papers vinden en inhoud van pagina's ophalen.

## Wanneer gebruik je het?

* Je doet regelmatig grondig onderzoek.

## Voorbeelden

{% code title="Voorbeeld 1: wat je typt" overflow="wrap" %}
```
Zoek recente wetenschappelijke artikelen over buurtpreventie en vat ze samen.
```
{% endcode %}

**Wat je krijgt:** Een overzicht met bronnen.

## Installeren

{% tabs %}
{% tab title="Claude Code" %}
Deze plugin staat in de **officiële Anthropic-marketplace**, die standaard al gekoppeld is:

```bash
/plugin install exa@claude-plugins-official
```

Of blader via `/plugin` → **Discover** en kies de plugin uit de lijst.
{% endtab %}
{% endtabs %}

Community-skills zijn niet door Anthropic gecontroleerd. Lees de `SKILL.md` voordat je installeert. Zie [Veilig installeren](../../basis/veiligheid.md).
