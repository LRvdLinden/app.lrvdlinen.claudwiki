# Raffle Winner Picker

| | |
| --- | --- |
| **Maker** | ComposioHQ (community) |
| **Werkt in** | Claude Code, Claude-app |
| **Kosten** | Gratis |
| **Bron** | [github.com/ComposioHQ/awesome-claude-skills/tree/master/raffle-winner-picker](https://github.com/ComposioHQ/awesome-claude-skills/tree/master/raffle-winner-picker) |

## Wat doet het?

Voor winacties, loterijen en verlotingen: Claude kiest willekeurige winnaars uit een lijst, CSV of Google Sheet, op een controleerbare manier.

## Wanneer gebruik je het?

* Je organiseert een winactie of verloting.

## Voorbeelden

{% code title="Voorbeeld 1: wat je typt" overflow="wrap" %}
```
Kies 3 winnaars uit deze lijst van inschrijvers, zonder dubbele e-mailadressen.
```
{% endcode %}

**Wat je krijgt:** Drie winnaars met uitleg van de trekking.

## Installeren

{% tabs %}
{% tab title="Claude-app" %}
1. Download de repo als ZIP: [github.com/ComposioHQ/awesome-claude-skills](https://github.com/ComposioHQ/awesome-claude-skills) → **Code → Download ZIP**.
2. Pak uit en zoek de map `raffle-winner-picker` (daarin staat `SKILL.md`).
3. Maak van **alleen die map** een nieuwe ZIP. De mapnaam moet gelijk zijn aan de skillnaam.
4. Ga naar **Instellingen → Mogelijkheden → Skills** en klik op **Skill uploaden**.
5. Zet de skill aan.

Skills in de Claude-app vragen een Pro-, Max-, Team- of Enterprise-abonnement en **Code-uitvoering en bestanden maken** moet aanstaan.
{% endtab %}
{% endtabs %}
