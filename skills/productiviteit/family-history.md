# Family History Research

| | |
| --- | --- |
| **Maker** | emaynard (community) |
| **Werkt in** | Claude-app, Claude Code |
| **Kosten** | Gratis |
| **Bron** | [github.com/emaynard/claude-family-history-research-skill](https://github.com/emaynard/claude-family-history-research-skill) |

## Wat doet het?

Helpt je genealogieonderzoek te structureren: wat weet je al, welke bronnen raadpleeg je, hoe noteer je bevindingen en wat zijn de volgende stappen.

## Wanneer gebruik je het?

* Je zoekt je familiegeschiedenis uit.

## Voorbeelden

{% code title="Voorbeeld 1: wat je typt" overflow="wrap" %}
```
Help me een onderzoeksplan te maken voor mijn overgrootvader, geboren rond 1890 in Gelderland.
```
{% endcode %}

**Wat je krijgt:** Een plan met bronnen zoals archieven en registers.

## Installeren

{% tabs %}
{% tab title="Claude-app" %}
1. Download de repo als ZIP: [github.com/emaynard/claude-family-history-research-skill](https://github.com/emaynard/claude-family-history-research-skill) → **Code → Download ZIP**.
2. Pak uit en zoek de map `(de skillmap met SKILL.md)` (daarin staat `SKILL.md`).
3. Maak van **alleen die map** een nieuwe ZIP. De mapnaam moet gelijk zijn aan de skillnaam.
4. Ga naar **Instellingen → Mogelijkheden → Skills** en klik op **Skill uploaden**.
5. Zet de skill aan.

Skills in de Claude-app vragen een Pro-, Max-, Team- of Enterprise-abonnement en **Code-uitvoering en bestanden maken** moet aanstaan.
{% endtab %}
{% endtabs %}
