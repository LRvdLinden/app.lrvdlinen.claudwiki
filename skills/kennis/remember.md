# Remember

| | |
| --- | --- |

| **Werkt in** | Claude Code |
| **Kosten** | Gratis |

## Wat doet het?

Remember haalt de kern uit je gesprekken, vat ze samen en comprimeert ze tot logboeken per dag. Zo weet Claude morgen nog wat je gisteren deed.

## Wanneer gebruik je het?

* Je werkt elke dag aan hetzelfde project.

{% tabs %}

Deze plugin staat in de **officiële Anthropic-marketplace**, die standaard al gekoppeld is:

```bash

```

Of blader via `/plugin` → **Discover** en kies de plugin uit de lijst.
