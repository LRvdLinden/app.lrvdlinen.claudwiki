# Airtable

| | |
| --- | --- |
| **Maker** | Airtable · officiële Claude-marketplace |
| **Werkt in** | Claude Code |
| **Kosten** | Plugin gratis; je hebt een account bij Airtable nodig |
| **Bron** | [www.airtable.com](https://www.airtable.com) |

## Wat doet het?

Met de Airtable-plugin leest en schrijft Claude gestructureerde data in Airtable, voor product, marketing, sales, operations, HR of een eigen bedrijfsapp. Je data blijft zichtbaar in de vertrouwde Airtable-weergaven.

## Wanneer gebruik je het?

* Je houdt lijsten of processen bij in Airtable.

## Voorbeelden

{% code title="Voorbeeld 1: wat je typt" overflow="wrap" %}
```
Voeg de inschrijvingen uit deze mail toe aan onze Airtable 'Vrijwilligers'.
```
{% endcode %}

**Wat je krijgt:** Nieuwe rijen in je Airtable-basis.

## Installeren

{% tabs %}
{% tab title="Claude Code" %}
Deze plugin staat in de **officiële Anthropic-marketplace**, die standaard al gekoppeld is:

```bash
/plugin install airtable@claude-plugins-official
```

Of blader via `/plugin` → **Discover** en kies de plugin uit de lijst.
