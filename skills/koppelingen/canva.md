# Canva

| | |
| --- | --- |
| **Maker** | Canva · officiële Claude-marketplace |
| **Werkt in** | Claude Code |
| **Kosten** | Plugin gratis; je hebt een account bij Canva nodig |
| **Bron** | [www.canva.com](https://www.canva.com) |

## Wat doet het?

Met de Canva-plugin maakt Claude ontwerpen in Canva, past ze aan, zet ze om naar andere formaten (bijvoorbeeld van post naar story) en controleert of ze bij je merk passen. Hij werkt via de officiële Canva MCP-server.

## Wanneer gebruik je het?

* Je maakt social posts of flyers in Canva.
* Je wilt één ontwerp in meerdere formaten.

## Voorbeelden

{% code title="Voorbeeld 1: wat je typt" overflow="wrap" %}
```
Maak van deze Instagram-post ook een story en een LinkedIn-banner.
```
{% endcode %}

**Wat je krijgt:** Drie Canva-ontwerpen in de juiste formaten.

## Installeren

{% tabs %}
{% tab title="Claude Code" %}
Deze plugin staat in de **officiële Anthropic-marketplace**, die standaard al gekoppeld is:

```bash
/plugin install canva@claude-plugins-official
```

Of blader via `/plugin` → **Discover** en kies de plugin uit de lijst.
