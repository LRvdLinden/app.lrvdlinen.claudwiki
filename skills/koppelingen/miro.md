# Miro

| | |
| --- | --- |
| **Maker** | Miro · officiële Claude-marketplace |
| **Werkt in** | Claude Code |
| **Kosten** | Plugin gratis; je hebt een account bij Miro nodig |
| **Bron** | [miro.com](https://miro.com) |

## Wat doet het?

De Miro-plugin geeft Claude veilige toegang tot je Miro-borden. Hij leest wat er op een bord staat, maakt diagrammen en kan een brainstorm of flow op het bord vertalen naar een plan of code.

## Wanneer gebruik je het?

* Je brainstormt of plant in Miro.

## Voorbeelden

{% code title="Voorbeeld 1: wat je typt" overflow="wrap" %}
```
Maak van de sticky notes op ons retro-bord een lijst met acties.
```
{% endcode %}

**Wat je krijgt:** Een gestructureerde actielijst.
