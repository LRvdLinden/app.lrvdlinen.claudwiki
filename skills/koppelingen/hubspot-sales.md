# HubSpot Sales

| | |
| --- | --- |
| **Maker** | HubSpot · officiële Claude-marketplace |
| **Werkt in** | Claude Code |
| **Kosten** | Plugin gratis; je hebt een HubSpot-account nodig |
| **Bron** | [www.hubspot.com](https://www.hubspot.com) |

## Wat doet het?

Skills van HubSpot zelf voor de complete salesdag: contacten en deals importeren, een geprioriteerde ochtendbriefing, gesprekken voorbereiden met alle CRM-context en persoonlijke follow-ups opstellen.

## Wanneer gebruik je het?

* Je verkoopt met HubSpot als CRM.

## Voorbeelden

{% code title="Voorbeeld 1: wat je typt" overflow="wrap" %}
```
Geef me mijn ochtendbriefing: welke deals vragen vandaag aandacht?
```
{% endcode %}

**Wat je krijgt:** Een geprioriteerde lijst met acties.

## Installeren

{% tabs %}
{% tab title="Claude Code" %}
Deze plugin staat in de **officiële Anthropic-marketplace**, die standaard al gekoppeld is:

```bash
/plugin install hubspot-sales@claude-plugins-official
```

Of blader via `/plugin` → **Discover** en kies de plugin uit de lijst.
{% endtab %}
{% endtabs %}

{% hint style="warning" %}
Community-skills zijn niet door Anthropic gecontroleerd. Lees de `SKILL.md` voordat je installeert. Zie [Veilig installeren](../../basis/veiligheid.md).
{% endhint %}
