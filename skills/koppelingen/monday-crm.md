# monday CRM

| | |
| --- | --- |
| **Maker** | monday.com · officiële Claude-marketplace |
| **Werkt in** | Claude Code |
| **Kosten** | Plugin gratis; je hebt een account bij monday.com nodig |
| **Bron** | [monday.com](https://monday.com) |

## Wat doet het?

Met deze plugin bestuur je monday CRM in gewone taal. Bouw een pipeline vanaf nul, begin de dag met een gerangschikte dealbriefing, maak een forecast-dashboard, controleer de gezondheid van je borden, schoon rommelige data op en maak van vergadernotities deal-updates.

## Wanneer gebruik je het?

* Je gebruikt monday.com als CRM.

## Voorbeelden

{% code title="Voorbeeld 1: wat je typt" overflow="wrap" %}
```
Maak van deze vergadernotities updates voor de juiste deals.
```
{% endcode %}

**Wat je krijgt:** Bijgewerkte deals in monday CRM.
