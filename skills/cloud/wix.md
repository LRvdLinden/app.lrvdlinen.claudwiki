# Wix

| | |
| --- | --- |
| **Maker** | Wix · officiële Claude-marketplace |
| **Werkt in** | Claude Code |
| **Kosten** | Plugin gratis; je hebt een Wix-account nodig |
| **Bron** | [dev.wix.com/docs/wix-cli/guides/development/about-wix-skills](https://dev.wix.com/docs/wix-cli/guides/development/about-wix-skills) |

## Wat doet het?

Skills om Wix-sites en -apps te bouwen: dashboard-extensies, backend-API's, site-widgets en service-plugins met het Wix Design System, plus een MCP-server voor sitebeheer.

## Wanneer gebruik je het?

* Je website draait op Wix.

## Voorbeelden

{% code title="Voorbeeld 1: wat je typt" overflow="wrap" %}
```
Voeg een widget met de komende activiteiten toe aan mijn Wix-site.
```
{% endcode %}

**Wat je krijgt:** Een werkende site-widget.

## Installeren

{% tabs %}
{% tab title="Claude Code" %}
Deze plugin staat in de **officiële Anthropic-marketplace**, die standaard al gekoppeld is:

```bash
/plugin install wix@claude-plugins-official
```

Of blader via `/plugin` → **Discover** en kies de plugin uit de lijst.
{% endtab %}
{% endtabs %}

{% hint style="warning" %}
Community-skills zijn niet door Anthropic gecontroleerd. Lees de `SKILL.md` voordat je installeert. Zie [Veilig installeren](../../basis/veiligheid.md).
{% endhint %}
