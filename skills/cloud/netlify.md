# Netlify

| | |
| --- | --- |
| **Maker** | Netlify · officiële Claude-marketplace |
| **Werkt in** | Claude Code |
| **Kosten** | Plugin gratis; je hebt een Netlify-account nodig |
| **Bron** | [github.com/netlify/context-and-tools](https://github.com/netlify/context-and-tools) |

## Wat doet het?

Skills voor het hele Netlify-platform: (edge) functions, blobs, database, image CDN, formulieren, configuratie, de CLI, frameworks, caching, de AI-gateway en deployen.

## Wanneer gebruik je het?

* Je host op Netlify.

## Voorbeelden

{% code title="Voorbeeld 1: wat je typt" overflow="wrap" %}
```
Voeg een contactformulier toe met Netlify Forms en een bedankpagina.
```
{% endcode %}

**Wat je krijgt:** Een werkend formulier zonder eigen backend.

## Installeren

{% tabs %}
{% tab title="Claude Code" %}
Deze plugin staat in de **officiële Anthropic-marketplace**, die standaard al gekoppeld is:

```bash
/plugin install netlify-skills@claude-plugins-official
```

Of blader via `/plugin` → **Discover** en kies de plugin uit de lijst.
{% endtab %}
{% endtabs %}

Community-skills zijn niet door Anthropic gecontroleerd. Lees de `SKILL.md` voordat je installeert. Zie [Veilig installeren](../../basis/veiligheid.md).
