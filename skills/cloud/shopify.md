# Shopify AI Toolkit

| | |
| --- | --- |
| **Maker** | Shopify · officiële Claude-marketplace |
| **Werkt in** | Claude Code |
| **Kosten** | Plugin gratis; je hebt een Shopify-winkel of partneraccount nodig |
| **Bron** | [shopify.dev](https://shopify.dev) |

## Wat doet het?

De AI Toolkit van Shopify bevat 18 ontwikkelskills: documentatie doorzoeken, API-schema's, GraphQL- en Liquid-code valideren, Hydrogen-storefronts, Polaris UI-extensies en winkelbeheer.

## Wanneer gebruik je het?

* Je bouwt een Shopify-thema, -app of -winkel.

## Voorbeelden

{% code title="Voorbeeld 1: wat je typt" overflow="wrap" %}
```
Pas het Liquid-template aan zodat de levertijd onder de prijs staat.
```
{% endcode %}

**Wat je krijgt:** Gevalideerde Liquid-code.

## Installeren

{% tabs %}
{% tab title="Claude Code" %}
Deze plugin staat in de **officiële Anthropic-marketplace**, die standaard al gekoppeld is:

```bash
/plugin install shopify-ai-toolkit@claude-plugins-official
```

Of blader via `/plugin` → **Discover** en kies de plugin uit de lijst.
{% endtab %}
{% endtabs %}

{% hint style="warning" %}
Community-skills zijn niet door Anthropic gecontroleerd. Lees de `SKILL.md` voordat je installeert. Zie [Veilig installeren](../../basis/veiligheid.md).
{% endhint %}
