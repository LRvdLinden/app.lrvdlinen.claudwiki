# Build with WordPress

| | |
| --- | --- |
| **Maker** | WordPress · officiële Claude-marketplace |
| **Werkt in** | Claude Code |
| **Kosten** | Gratis |
| **Bron** | [developer.wordpress.com/wordpress-com-claude-code-plugin/](https://developer.wordpress.com/wordpress-com-claude-code-plugin/) |

## Wat doet het?

Alles om met WordPress te bouwen: van thema's en plugins tot WooCommerce-webshops en het live zetten van je site.

## Wanneer gebruik je het?

* Je website draait op WordPress.

## Voorbeelden

{% code title="Voorbeeld 1: wat je typt" overflow="wrap" %}
```
Maak een eenvoudige WordPress-plugin die een melding bovenaan de site toont.
```
{% endcode %}

**Wat je krijgt:** Een installeerbare plugin.

## Installeren

{% tabs %}
{% tab title="Claude Code" %}
Deze plugin staat in de **officiële Anthropic-marketplace**, die standaard al gekoppeld is:

```bash
/plugin install build-with-wordpress@claude-plugins-official
```

Of blader via `/plugin` → **Discover** en kies de plugin uit de lijst.
{% endtab %}
{% endtabs %}

{% hint style="warning" %}
Community-skills zijn niet door Anthropic gecontroleerd. Lees de `SKILL.md` voordat je installeert. Zie [Veilig installeren](../../basis/veiligheid.md).
{% endhint %}
