# Juridisch (rol-plugin)

| | |
| --- | --- |
| **Maker** | Anthropic (officieel) |
| **Werkt in** | Claude-app (desktop), Claude Code |
| **Kosten** | Gratis (open source) |
| **Bron** | [github.com/anthropics/knowledge-work-plugins/tree/main/legal](https://github.com/anthropics/knowledge-work-plugins/tree/main/legal) |

## Wat doet het?

De rol-plugin **legal** van Anthropic bundelt skills, commando's en koppelingen voor deze functie. Contracten reviewen, NDA's triëren, compliance controleren en juridische risico's inschatten. Je roept de onderdelen aan als `/legal:<skill>`.

**Skills in deze plugin:** `review-contract`, `triage-nda`, `compliance-check`, `legal-risk-assessment`, `legal-response`, `meeting-briefing`, `vendor-check`, `brief`, `signature-request`.

Zie ook het [overzicht van alle rol-plugins](knowledge-work-plugins.md).

## Wanneer gebruik je het?

* Je werkt in deze rol en wilt vaste, goede workflows.
* Je wilt de plugin aanpassen met je eigen tools en werkwijze.

## Voorbeelden

{% code title="Voorbeeld 1: wat je typt" overflow="wrap" %}
```
/legal:review-contract
```
{% endcode %}

**Wat je krijgt:** De bijbehorende workflow, stap voor stap.

## Installeren

{% tabs %}
{% tab title="Claude-app" %}
Installeer de plugin in de Claude-desktopapp via [claude.com/plugins](https://claude.com/plugins/). Skills gaan vanzelf aan en de commando's verschijnen in je sessie.
{% endtab %}

{% tab title="Claude Code" %}
```bash
claude plugin marketplace add anthropics/knowledge-work-plugins
claude plugin install legal@knowledge-work-plugins
```
{% endtab %}
{% endtabs %}

{% hint style="success" %}
**Tips**

* Pas de plugin aan je eigen tools aan via het bestand `.mcp.json` in de plugin.
{% endhint %}
