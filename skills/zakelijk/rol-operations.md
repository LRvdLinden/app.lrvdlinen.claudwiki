# Operations (rol-plugin)

| | |
| --- | --- |
| **Maker** | Anthropic (officieel) |
| **Werkt in** | Claude-app (desktop), Claude Code |
| **Kosten** | Gratis (open source) |
| **Bron** | [github.com/anthropics/knowledge-work-plugins/tree/main/operations](https://github.com/anthropics/knowledge-work-plugins/tree/main/operations) |

## Wat doet het?

De rol-plugin **operations** van Anthropic bundelt skills, commando's en koppelingen voor deze functie. Leveranciersbeheer, procesdocumentatie, wijzigingsbeheer, capaciteitsplanning en compliance. Je roept de onderdelen aan als `/operations:<skill>`.

**Skills in deze plugin:** `process-doc`, `runbook`, `change-request`, `capacity-plan`, `risk-assessment`, `vendor-review`, `status-report`, `compliance-tracking`, `process-optimization`.

Zie ook het [overzicht van alle rol-plugins](knowledge-work-plugins.md).

## Wanneer gebruik je het?

* Je werkt in deze rol en wilt vaste, goede workflows.
* Je wilt de plugin aanpassen met je eigen tools en werkwijze.

## Voorbeelden

{% code title="Voorbeeld 1: wat je typt" overflow="wrap" %}
```
/operations:process-doc
```
{% endcode %}

**Wat je krijgt:** De bijbehorende workflow, stap voor stap.

## Installeren

{% tabs %}
{% tab title="Claude-app" %}
Installeer de plugin in de Claude-desktopapp via [claude.com/plugins](https://claude.com/plugins/). Skills gaan vanzelf aan en de commando's verschijnen in je sessie.
{% endtab %}

{% tab title="Claude Code" %}
```bash
claude plugin marketplace add anthropics/knowledge-work-plugins
claude plugin install operations@knowledge-work-plugins
```
{% endtab %}
{% endtabs %}

{% hint style="success" %}
**Tips**

* Pas de plugin aan je eigen tools aan via het bestand `.mcp.json` in de plugin.
{% endhint %}
