# Obsidian Visual Skills

| | |
| --- | --- |
| **Maker** | Axton Liu (community) |
| **Works in** | Claude Code |
| **Cost** | Free |
| **Source** | [github.com/axtonliu/axton-obsidian-visual-skills](https://github.com/axtonliu/axton-obsidian-visual-skills) |

## What does it do?

Three skills: **excalidraw-diagram**, **mermaid-visualizer** and **obsidian-canvas-creator**. They turn text into diagrams you open directly in Obsidian.

## When do you use it?

* You use Obsidian and want to visualise notes.

## Examples

{% code title="Example 1: what you type" overflow="wrap" %}
```
Make an Obsidian canvas of these project notes.
```
{% endcode %}

**What you get:** A .canvas file with cards and connections.

## Install

{% tabs %}
{% tab title="Claude Code" %}
First add the marketplace, then install the plugin. Type this in a Claude Code session:

```bash
/plugin marketplace add axtonliu/axton-obsidian-visual-skills
/plugin install obsidian-visual-skills
```

Restart Claude Code if the skill doesn't appear right away. Check with `/plugin` that it is enabled.
{% endtab %}
{% endtabs %}
