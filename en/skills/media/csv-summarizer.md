# CSV Data Summarizer

| | |
| --- | --- |
| **Maker** | coffeefuelbump (community) |
| **Works in** | Claude app, Claude Code |
| **Cost** | Free |
| **Source** | [github.com/coffeefuelbump/csv-data-summarizer-claude-skill](https://github.com/coffeefuelbump/csv-data-summarizer-claude-skill) |

## What does it do?

Automatically detects what kind of data you have (sales, customers, financial, survey) and creates a complete analysis with statistics, correlations, distributions, trends and visualisations, without you first having to say what you want to know.

## When do you use it?

* You have an export and want to know quickly what's in it.

## Examples

{% code title="Example 1: what you type" overflow="wrap" %}
```
(upload survey.csv)
```
{% endcode %}

**What you get:** A summary with the main insights and charts.

## Install

{% tabs %}
{% tab title="Claude app" %}
1. Download the repo as a ZIP: [github.com/coffeefuelbump/csv-data-summarizer-claude-skill](https://github.com/coffeefuelbump/csv-data-summarizer-claude-skill) → **Code → Download ZIP**.
2. Unzip and find the folder `(the root folder with SKILL.md)` (it contains `SKILL.md`).
3. Zip **only that folder** into a new ZIP. The folder name must match the skill name.
4. Go to **Settings → Capabilities → Skills** and click **Upload skill**.
5. Switch the skill on.

Skills in the Claude app require a Pro, Max, Team or Enterprise plan, and **Code execution and file creation** must be turned on.
{% endtab %}
{% endtabs %}
