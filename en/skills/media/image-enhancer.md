# Image Enhancer

| | |
| --- | --- |
| **Maker** | ComposioHQ (community) |
| **Works in** | Claude Code |
| **Cost** | Free |
| **Source** | [github.com/ComposioHQ/awesome-claude-skills/tree/master/image-enhancer](https://github.com/ComposioHQ/awesome-claude-skills/tree/master/image-enhancer) |

## What does it do?

Improves resolution, sharpness and clarity of images, especially screenshots. Ideal for documentation, presentations and social media.

## When do you use it?

* Your screenshots look blurry in your presentation or App Store page.

## Examples

{% code title="Example 1: what you type" overflow="wrap" %}
```
Sharpen all screenshots in this folder for my presentation.
```
{% endcode %}

**What you get:** Improved images.

## Install

```bash
cp -r awesome-claude-skills/image-enhancer ~/.claude/skills/
```
