# Mapbox

| | |
| --- | --- |
| **Maker** | Mapbox · official Claude marketplace |
| **Works in** | Claude Code |
| **Cost** | Plugin free; requires a Mapbox account |
| **Source** | [www.mapbox.com](https://www.mapbox.com) |

## What does it do?

Skills and MCP servers from Mapbox for location-aware apps: geospatial tools, style management and patterns for web, iOS, Android and AI agent frameworks.

## When do you use it?

* Your app shows maps or works with locations.

## Examples

{% code title="Example 1: what you type" overflow="wrap" %}
```
Show today's alerts as markers on a Mapbox map in my iOS app.
```
{% endcode %}

**What you get:** SwiftUI code with a Mapbox map and markers.
