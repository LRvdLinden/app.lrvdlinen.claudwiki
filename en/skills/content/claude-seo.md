# Claude SEO

| | |
| --- | --- |
| **Maker** | Agrici Daniel (community) |
| **Works in** | Claude Code |
| **Cost** | Free (MIT) |
| **Source** | [github.com/AgriciDaniel/claude-seo](https://github.com/AgriciDaniel/claude-seo) |

## What does it do?

An SEO plugin with dozens of sub-skills and specialised agents: technical SEO, Core Web Vitals, E-E-A-T, schema.org, AI search engines (GEO), local SEO, e-commerce and international SEO.

## When do you use it?

* You want your website audited before you promote it.

## Examples

{% code title="Example 1: what you type" overflow="wrap" %}
```
Do a full SEO audit of https://yourwebsite.com
```
{% endcode %}

**What you get:** A report with priorities and concrete fixes.

## Install

{% tabs %}
{% tab title="Claude Code" %}
First add the marketplace, then install the plugin. Type this in a Claude Code session:

```bash
/plugin marketplace add AgriciDaniel/claude-seo
/plugin install claude-seo@agricidaniel-claude-seo
```

Restart Claude Code if the skill doesn't appear right away. Check with `/plugin` that it is enabled.
{% endtab %}
{% endtabs %}
