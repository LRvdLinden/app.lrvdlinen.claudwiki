# Marketing Skills

| | |
| --- | --- |
| **Maker** | Corey Haines (community) |
| **Works in** | Claude Code (+ Codex, Cursor and more) |
| **Cost** | Free (MIT) |
| **Source** | [github.com/coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills) |

## What does it do?

A collection for marketers and founders. Including **copywriting** (pages, posts and ads), **social** (content for six platforms, including Instagram and TikTok), **content-strategy** (from goal to content plan and calendar), **marketing-psychology** (persuasion principles, hooks and calls to action), plus conversion optimisation, SEO and analytics.

## When do you use it?

* You want a landing page or ad that converts.
* You want a content calendar for your app.

## Examples

{% code title="Example 1: what you type" overflow="wrap" %}
```
Write three variants of the App Store description for my app, with different hooks.
```
{% endcode %}

**What you get:** Three well-argued variants.

{% code title="Example 2: what you type" overflow="wrap" %}
```
Make a 4-week Instagram content plan for the launch of my app.
```
{% endcode %}

**What you get:** A calendar with topics, formats and hooks.

## Install

{% tabs %}
{% tab title="Claude Code" %}
First add the marketplace, then install the plugin. Type this in a Claude Code session:

```bash
/plugin marketplace add coreyhaines31/marketingskills
/plugin install marketing-skills
```

Restart Claude Code if the skill doesn't appear right away. Check with `/plugin` that it is enabled.

`/plugin` only works in an interactive Claude Code session.
{% endtab %}

{% tab title="npx skills" %}
With the open-source [skills CLI](https://github.com/vercel-labs/skills) you install skills for Claude Code and other agents. All you need is Node.js:

```bash
npx skills add coreyhaines31/marketingskills -a claude-code
```

Add `-g` to install it globally (for all your projects). `npx skills list` shows what is installed.
{% endtab %}
{% endtabs %}

Community skills are not reviewed by Anthropic. Read the `SKILL.md` before you install. See [Install safely](../../basis/veiligheid.md).
{% endhint %}
