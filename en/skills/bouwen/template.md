# Skill template & specification

| | |
| --- | --- |
| **Maker** | Anthropic / agentskills.io |
| **Works in** | All agents that support the standard |
| **Cost** | Free |
| **Source** | [github.com/anthropics/skills/tree/main/template](https://github.com/anthropics/skills/tree/main/template) |

## What does it do?

The official repo contains a minimal template and the specification of the open **Agent Skills** standard ([agentskills.io](https://agentskills.io)). That standard is now supported by dozens of agents, so a skill you write once works in Claude Code, Codex, Cursor and more.

## When do you use it?

* You want to set up a skill from scratch yourself.

## Examples

{% code title="Example 1: what you type" overflow="wrap" %}
```
Use the official template to create a skill 'meeting-minutes'.
```
{% endcode %}

**What you get:** A folder with a valid SKILL.md.
