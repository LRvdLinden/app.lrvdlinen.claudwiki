# HubSpot Sales

| | |
| --- | --- |
| **Maker** | HubSpot · official Claude marketplace |
| **Works in** | Claude Code |
| **Cost** | Plugin free; requires a HubSpot account |
| **Source** | [www.hubspot.com](https://www.hubspot.com) |

## What does it do?

Skills from HubSpot itself for the complete sales day: import contacts and deals, a prioritised morning brief, prepare calls with full CRM context and draft personalised follow-ups.

## When do you use it?

* You sell with HubSpot as your CRM.

## Examples

{% code title="Example 1: what you type" overflow="wrap" %}
```
Give me my morning brief: which deals need attention today?
```
{% endcode %}

**What you get:** A prioritised list of actions.
