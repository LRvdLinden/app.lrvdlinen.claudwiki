# Dropbox

| | |
| --- | --- |
| **Maker** | Dropbox · official Claude marketplace |
| **Works in** | Claude Code |
| **Cost** | Plugin free; requires a Dropbox account |
| **Source** | [www.dropbox.com](https://www.dropbox.com) |

## What does it do?

The Dropbox plugin connects your Dropbox to Claude: search and organise files, save what Claude makes straight away and create sharing links. Your existing Dropbox permissions stay in place.

## When do you use it?

* You keep your files in Dropbox.

## Examples

{% code title="Example 1: what you type" overflow="wrap" %}
```
Save this presentation in Dropbox/Council and give me a sharing link.
```
{% endcode %}

**What you get:** The file in Dropbox plus a link.
