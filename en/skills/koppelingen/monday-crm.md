# monday CRM

| | |
| --- | --- |
| **Maker** | monday.com · official Claude marketplace |
| **Works in** | Claude Code |
| **Cost** | Plugin free; requires a monday.com account |
| **Source** | [monday.com](https://monday.com) |

## What does it do?

With this plugin you run monday CRM in plain language. Build a pipeline from scratch, start the day with a ranked deal briefing, create a forecast dashboard, audit board health, clean up messy data and turn meeting notes into deal updates.

## When do you use it?

* You use monday.com as your CRM.

## Examples

{% code title="Example 1: what you type" overflow="wrap" %}
```
Turn these meeting notes into updates for the right deals.
```
{% endcode %}

**What you get:** Updated deals in monday CRM.
