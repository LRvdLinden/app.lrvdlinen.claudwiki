# Miro

| | |
| --- | --- |
| **Maker** | Miro · official Claude marketplace |
| **Works in** | Claude Code |
| **Cost** | Plugin free; requires a Miro account |
| **Source** | [miro.com](https://miro.com) |

## What does it do?

The Miro plugin gives Claude secure access to your Miro boards. It reads what's on a board, creates diagrams and can translate a brainstorm or flow on the board into a plan or code.

## When do you use it?

* You brainstorm or plan in Miro.

## Examples

{% code title="Example 1: what you type" overflow="wrap" %}
```
Turn the sticky notes on our retro board into a list of actions.
```
{% endcode %}

**What you get:** A structured action list.
