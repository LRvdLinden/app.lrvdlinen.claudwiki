# Canva

| | |
| --- | --- |
| **Maker** | Canva · official Claude marketplace |
| **Works in** | Claude Code |
| **Cost** | Plugin free; requires a Canva account |
| **Source** | [www.canva.com](https://www.canva.com) |

## What does it do?

With the Canva plugin Claude creates designs in Canva, edits them, resizes them to other formats (for example from post to story) and checks whether they fit your brand. It works through the official Canva MCP server.

## When do you use it?

* You make social posts or flyers in Canva.
* You want one design in several formats.

{% code title="Example 1: what you type" overflow="wrap" %}
