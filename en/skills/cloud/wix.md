# Wix

| | |
| --- | --- |
| **Maker** | Wix · official Claude marketplace |
| **Works in** | Claude Code |
| **Cost** | Plugin free; requires a Wix account |
| **Source** | [dev.wix.com/docs/wix-cli/guides/development/about-wix-skills](https://dev.wix.com/docs/wix-cli/guides/development/about-wix-skills) |

## What does it do?

Skills for building Wix sites and apps: dashboard extensions, backend APIs, site widgets and service plugins with the Wix Design System, plus an MCP server for site management.

## When do you use it?

* Your website runs on Wix.

## Examples

{% code title="Example 1: what you type" overflow="wrap" %}
```
Add a widget with upcoming events to my Wix site.
```
{% endcode %}

**What you get:** A working site widget.

## Install

{% tabs %}
{% tab title="Claude Code" %}
This plugin is in the **official Anthropic marketplace**, which is connected by default:

```bash
/plugin install wix@claude-plugins-official
```

Or browse via `/plugin` → **Discover** and pick the plugin from the list.

{% endtab %}
