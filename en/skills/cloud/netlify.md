# Netlify

| | |
| --- | --- |
| **Maker** | Netlify · official Claude marketplace |
| **Works in** | Claude Code |
| **Cost** | Plugin free; requires a Netlify account |
| **Source** | [github.com/netlify/context-and-tools](https://github.com/netlify/context-and-tools) |

## What does it do?

Skills for the whole Netlify platform: (edge) functions, blobs, database, image CDN, forms, configuration, the CLI, frameworks, caching, the AI gateway and deployment.

## When do you use it?

* You host on Netlify.

## Examples

{% code title="Example 1: what you type" overflow="wrap" %}
```
Add a contact form with Netlify Forms and a thank-you page.
```
{% endcode %}

**What you get:** A working form without your own backend.

## Install

{% tabs %}
{% tab title="Claude Code" %}

```bash
/plugin install netlify-skills@claude-plugins-official
```

Or browse via `/plugin` → **Discover** and pick the plugin from the list.
