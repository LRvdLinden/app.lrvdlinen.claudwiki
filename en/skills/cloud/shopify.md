# Shopify AI Toolkit

| | |
| --- | --- |
| **Maker** | Shopify · official Claude marketplace |
| **Works in** | Claude Code |
| **Cost** | Plugin free; requires a Shopify account |
| **Source** | [shopify.dev](https://shopify.dev) |

## What does it do?

Shopify's AI Toolkit contains 18 development skills: documentation search, API schemas, validating GraphQL and Liquid code, Hydrogen storefronts, Polaris UI extensions and store management.

## When do you use it?

* You're building a Shopify theme, app or store.

## Examples

{% code title="Example 1: what you type" overflow="wrap" %}
```
Change the Liquid template so the delivery time shows below the price.
```
{% endcode %}

**What you get:** Validated Liquid code.
