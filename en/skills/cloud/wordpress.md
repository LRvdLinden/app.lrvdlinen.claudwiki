# Build with WordPress

| | |
| --- | --- |
| **Maker** | WordPress · official Claude marketplace |
| **Works in** | Claude Code |
| **Cost** | Free |
| **Source** | [developer.wordpress.com/wordpress-com-claude-code-plugin/](https://developer.wordpress.com/wordpress-com-claude-code-plugin/) |

## What does it do?

Everything for building with WordPress: from themes and plugins to WooCommerce shops and putting your site live.

## When do you use it?

* Your website runs on WordPress.

## Examples

{% code title="Example 1: what you type" overflow="wrap" %}
```
Create a simple WordPress plugin that shows a notice at the top of the site.
```
{% endcode %}

**What you get:** An installable plugin.

## Install

{% tabs %}
{% tab title="Claude Code" %}
This plugin is in the **official Anthropic marketplace**, which is connected by default:

```bash
/plugin install build-with-wordpress@claude-plugins-official
```

Or browse via `/plugin` → **Discover** and pick the plugin from the list.
