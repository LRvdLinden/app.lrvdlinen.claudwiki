# Exa Search

| | |
| --- | --- |
| **Maker** | Exa · official Claude marketplace |
| **Works in** | Claude Code |
| **Cost** | Plugin free; requires an API key from Exa |
| **Source** | [exa.ai/docs/reference/exa-mcp](https://exa.ai/docs/reference/exa-mcp) |

## What does it do?

Exa gives Claude powerful web search tools and research skills: thorough web search, researching people and companies, finding academic papers and extracting page content.

## When do you use it?

* You regularly do in-depth research.

## Examples

{% code title="Example 1: what you type" overflow="wrap" %}
```
Find recent academic papers on neighbourhood watch and summarise them.
```
{% endcode %}

**What you get:** An overview with sources.
