# Tavily

| | |
| --- | --- |
| **Maker** | Tavily · official Claude marketplace |
| **Works in** | Claude Code |
| **Cost** | Plugin free; requires an API key from Tavily |
| **Source** | [www.tavily.com/](https://www.tavily.com/) |

## What does it do?

With the Tavily plugin Claude builds AI applications that use current web data through Tavily's search, extract, crawl and research APIs.

## When do you use it?

* You're building an app that needs current information from the web.

## Examples

{% code title="Example 1: what you type" overflow="wrap" %}
```
Build a feature that summarises the news about my town every morning.
```
{% endcode %}

**What you get:** Code that uses Tavily to fetch the news.
