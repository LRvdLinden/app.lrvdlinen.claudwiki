# Family History Research

| | |
| --- | --- |
| **Maker** | emaynard (community) |
| **Works in** | Claude app, Claude Code |
| **Cost** | Free |
| **Source** | [github.com/emaynard/claude-family-history-research-skill](https://github.com/emaynard/claude-family-history-research-skill) |

## What does it do?

Helps you structure genealogy research: what do you already know, which sources do you consult, how do you record findings and what are the next steps.

## When do you use it?

* You are researching your family history.

## Examples

{% code title="Example 1: what you type" overflow="wrap" %}
```
Help me make a research plan for my great-grandfather, born around 1890 in Gelderland.
```
{% endcode %}

**What you get:** A plan with sources such as archives and registers.

## Install

{% tabs %}
{% tab title="Claude app" %}
1. Download the repo as a ZIP: [github.com/emaynard/claude-family-history-research-skill](https://github.com/emaynard/claude-family-history-research-skill) → **Code → Download ZIP**.
2. Unzip and find the folder `(the skill folder with SKILL.md)` (it contains `SKILL.md`).
3. Zip **only that folder** into a new ZIP. The folder name must match the skill name.
4. Go to **Settings → Capabilities → Skills** and click **Upload skill**.
5. Switch the skill on.

Skills in the Claude app require a Pro, Max, Team or Enterprise plan, and **Code execution and file creation** must be turned on.
{% endtab %}
{% endtabs %}
