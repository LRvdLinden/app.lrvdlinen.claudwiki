# Raffle Winner Picker

| | |
| --- | --- |
| **Maker** | ComposioHQ (community) |
| **Works in** | Claude Code, Claude app |
| **Cost** | Free |
| **Source** | [github.com/ComposioHQ/awesome-claude-skills/tree/master/raffle-winner-picker](https://github.com/ComposioHQ/awesome-claude-skills/tree/master/raffle-winner-picker) |

## What does it do?

For giveaways, raffles and draws: Claude picks random winners from a list, CSV or Google Sheet, in a verifiable way.

## When do you use it?

* You are organising a giveaway or raffle.

## Examples

{% code title="Example 1: what you type" overflow="wrap" %}
```
Pick 3 winners from this list of entries, without duplicate email addresses.
```
{% endcode %}

**What you get:** Three winners with an explanation of the draw.

## Install

{% tabs %}
{% tab title="Claude app" %}
1. Download the repo as a ZIP: [github.com/ComposioHQ/awesome-claude-skills](https://github.com/ComposioHQ/awesome-claude-skills) → **Code → Download ZIP**.
2. Unzip and find the folder `raffle-winner-picker` (it contains `SKILL.md`).
3. Zip **only that folder** into a new ZIP. The folder name must match the skill name.
4. Go to **Settings → Capabilities → Skills** and click **Upload skill**.
5. Switch the skill on.

Skills in the Claude app require a Pro, Max, Team or Enterprise plan, and **Code execution and file creation** must be turned on.
