# Skill adviser

Not sure which skill you need? Describe in plain language what you want to do, and the adviser searches **461 skills and plugins** for the best options, with an explanation and install command.

<a href="https://lrvdlinden.github.io/app.lrvdlinen.claudwiki/en/adviseur/" class="button primary" data-icon="magnifying-glass">Open the Skill adviser</a>

{% tabs %}
{% tab title="In your browser" %}
Open the [Skill adviser](https://lrvdlinden.github.io/app.lrvdlinen.claudwiki/en/adviseur/) and type what you want, for example *"I want to make videos for Instagram"* or *"I'm building an iPhone app in SwiftUI"*.
{% endtab %}
{% tab title="As a skill in Claude" %}
Install the **skill-adviseur** skill. Then ask in any conversation: *"Which skill do I need to …?"* and Claude advises from the same catalogue (it answers in your language).

**Claude app:** download [skill-adviseur.zip](../../.gitbook/assets/skill-adviseur.zip) and upload it via **Settings → Capabilities → Skills → Upload skill**.
{% endtab %}
{% endtabs %}
