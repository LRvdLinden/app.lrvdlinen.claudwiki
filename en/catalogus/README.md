# Plugin catalogue

Anthropic's official marketplace (`claude-plugins-official`) currently has **315 plugins**: from Anthropic itself and from companies like Google, AWS, Microsoft, Stripe, Figma, Notion, Canva, Shopify and Supabase. This marketplace is connected by default in Claude Code.

{% hint style="info" %}
**Install:** type `/plugin install <name>@claude-plugins-official` in Claude Code, or browse via `/plugin` → **Discover**. Third-party plugins sometimes contain MCP servers or software that Anthropic doesn't control: only install what you trust.
{% endhint %}
