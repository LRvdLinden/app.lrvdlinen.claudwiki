Web Artifacts Builder

Bouwt grote, complexe webartifacts met React, Tailwind CSS en shadcn/ui.
Maker Anthropic (officieel)
Werkt in Claude-app, Claude Code, API
Kosten Gratis (Apache 2.0)
Bron github.com/anthropics/skills/tree/main/skills/web-artifacts-builder

Wat doet het?

Voor simpele pagina's heb je deze skill niet nodig. Maar wil je een groter artifact met meerdere onderdelen, state management of routing? Dan zet deze skill een moderne stack op (React, Tailwind CSS, shadcn/ui) en bundelt alles tot één artifact.

Wanneer gebruik je het?

  • Je wilt een uitgebreide tool of mini-app als artifact.
  • Je hebt meerdere schermen of componenten nodig.

Voorbeelden

Wat je krijgt: Een interactieve mini-app als artifact.

Installeren

Deze skill is al ingebouwd voor betaalde abonnementen.

  1. Open Instellingen → Mogelijkheden (Settings → Capabilities).
  2. Zet Code-uitvoering en bestanden maken aan.
  3. Scroll naar Skills en zet de skill aan.

Daarna vraag je gewoon in gewone taal wat je wilt; Claude laadt de skill zelf.

Voeg eerst de marketplace toe en installeer daarna de plugin. Typ dit in een Claude Code-sessie:

/plugin marketplace add anthropics/skills
/plugin install example-skills@anthropic-agent-skills

Herstart Claude Code als de skill niet meteen verschijnt. Controleer met /plugin of hij aanstaat.

Dit installeert het hele pakket example-skills (o.a. deze skill).

Met de open-source skills-CLI installeer je skills voor Claude Code én andere agents. Je hebt alleen Node.js nodig:

npx skills add anthropics/skills --skill web-artifacts-builder

Voeg -g toe om hem globaal (voor al je projecten) te installeren. Met npx skills list zie je wat er geïnstalleerd is.
