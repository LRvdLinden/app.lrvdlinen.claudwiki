# Locatie & kaarten

2 plugins. Installeren in Claude Code: `/plugin install <naam>@claude-plugins-official`.

| Plugin | Maker | Wat het doet (beschrijving van de maker) | Installeren |
| --- | --- | --- | --- |
| [**amazon-location-service**](https://github.com/awslabs/agent-plugins) |  | Guide developers through adding maps, places search, geocoding, routing, and other geospatial features with Amazon Location Service, including authentication setup, SDK integration, and best practices. | `/plugin install amazon-location-service@claude-plugins-official` |
| [**mapbox**](https://www.mapbox.com) | Mapbox | Mapbox skills and MCP servers for building location-aware applications with AI. Includes geospatial tools, style management, and patterns for web, iOS, Android, and AI agent frameworks. | `/plugin install mapbox@claude-plugins-official` |
