# Plugin-catalogus

De officiële marketplace van Anthropic (`claude-plugins-official`) telt op dit moment **315 plugins**: van Anthropic zelf en van bedrijven als Google, AWS, Microsoft, Stripe, Figma, Notion, Canva, Shopify en Supabase. Deze marketplace is in Claude Code standaard al gekoppeld.

{% hint style="info" %}
**Installeren:** typ in Claude Code `/plugin install <naam>@claude-plugins-official`, of blader via `/plugin` → **Discover**. Plugins van derden bevatten soms MCP-servers of software die Anthropic niet beheert: installeer alleen wat je vertrouwt.
{% endhint %}
