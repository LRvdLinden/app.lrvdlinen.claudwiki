# Testen

2 plugins. Installeren in Claude Code: `/plugin install <naam>@claude-plugins-official`.

| Plugin | Maker | Wat het doet (beschrijving van de maker) | Installeren |
| --- | --- | --- | --- |
| [**growthbook**](https://growthbook.io) | GrowthBook | A suite of agent skills for the full GrowthBook feature flag and experimentation lifecycle. | `/plugin install growthbook@claude-plugins-official` |
| [**playwright**](https://github.com/anthropics/claude-plugins-public/tree/main/external_plugins/playwright) |  | Browser automation and end-to-end testing MCP server by Microsoft. Enables Claude to interact with web pages, take screenshots, fill forms, click elements, and perform automated browser testing workflows. | `/plugin install playwright@claude-plugins-official` |
