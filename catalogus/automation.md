# Automatisering

3 plugins. Installeren in Claude Code: `/plugin install <naam>@claude-plugins-official`.

| Plugin | Maker | Wat het doet (beschrijving van de maker) | Installeren |
| --- | --- | --- | --- |
| [**browser-use**](https://browser-use.com) | Browser Use | Give Claude a real browser — your Chrome or a Browser Use Cloud browser. Use it whenever a task involves a website or web app: browsing, scraping and data extraction, filling forms, testing sites, taking screenshots, automating web workflows. | `/plugin install browser-use@claude-plugins-official` |
| [**synthflow**](https://synthflow.ai) | Synthflow | Connects Claude Code to the Synthflow AI voice-agent platform through its hosted MCP server, with skills for reviewing calls and auditing agent prompts, plus a docs-search connector. | `/plugin install synthflow@claude-plugins-official` |
| [**zyte-web-data**](https://www.zyte.com) | Zyte | Web scraping skills for Claude Code powered by the Zyte API — scrape sites, generate and run Scrapy spiders, define extraction schemas, and ship to Scrapy Cloud. | `/plugin install zyte-web-data@claude-plugins-official` |
