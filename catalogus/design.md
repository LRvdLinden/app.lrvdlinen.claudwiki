# Design

8 plugins. Installeren in Claude Code: `/plugin install <naam>@claude-plugins-official`.

| Plugin | Maker | Wat het doet (beschrijving van de maker) | Installeren |
| --- | --- | --- | --- |
| [**adobe-for-creativity**](https://github.com/adobe/skills/tree/main/plugins/creative-cloud/adobe-for-creativity) | Adobe | Harness Adobe's creative AI-powered tools to edit images, automate design workflows, and bring creative visions to life — from background removal to vectorization and professional retouching. | `/plugin install adobe-for-creativity@claude-plugins-official` |
| [**canva**](https://www.canva.com) | Canva | Create, edit, review, resize, and brand-check Canva designs with the Canva MCP server. | `/plugin install canva@claude-plugins-official` |
| [**figma**](https://github.com/figma/mcp-server-guide) |  | Figma design platform integration. Access design files, extract component information, read design tokens, and translate designs into code. Bridge the gap between design and development workflows. | `/plugin install figma@claude-plugins-official` |
| [**hyperframes**](https://hyperframes.heygen.com) | HeyGen | HyperFrames by HeyGen. Write HTML, render video. Compositions, GSAP and runtime adapter animations, captions, voiceovers, audio-reactive visuals, and website-to-video capture for HyperFrames. | `/plugin install hyperframes@claude-plugins-official` |
| [**miro**](https://miro.com) | Miro | Secure access to Miro boards. Enables AI to read board context, create diagrams, and generate code with enterprise-grade security. | `/plugin install miro@claude-plugins-official` |
| [**runway-api**](https://runwayml.com) | Runway | Get guidance for integrating video, image and audio generation with the Runway API and official SDKs. Connect to your Runway Dev account to inspect available models and task errors, manage Model Routers and existing real-time avatars, and inspect recorded routing decisions. | `/plugin install runway-api@claude-plugins-official` |
| [**superdesign**](https://superdesign.dev) | Superdesign dev, Inc. | Design or redesign frontend UI and marketing graphics on the Superdesign infinite canvas. Reads your codebase for context, sets up a design system, and generates branchable design drafts you refine. | `/plugin install superdesign@claude-plugins-official` |
| [**ui-theme-designer**](https://github.com/SAP/ui-theme-designer-plugins-for-coding-agents) | SAP SE | Plugin for coding agents working with UI theme designer. Bundles two skills: how-to and conceptual answers about UI theme designer on BTP, and questions about the SAP Design System and SAP Fiori design tokens — theme parameters and component-level parameter usage in UI5, UI5 Web Components, and Fundamental Styles. | `/plugin install ui-theme-designer@claude-plugins-official` |
